# Scene 07: прогулка по кадрам видео

Дата подготовки: 2026-09-19. Основание: запрос пользователя на новую седьмую сцену из нескольких экранов предоставленного видео, с переходами и скрытыми объектами для поиска. В этой итерации нет 360° и генерации окружения.

## Статус переноса в GitHub

**Медиа загружены в эту ветку и проверены по манифесту.** Шесть исходных `.webp` находятся в `public/assets/scene-07/`; их точные размеры и SHA-256 перечислены в `content/scene-07.manifest.json`. В публичный репозиторий не нужно загружать исходный MP4, аудио или метаданные.

После загрузки кадров выполнены:

```sh
npm run test:photo-walk
npm run build
```

Дополнительно проверены типы, контентные тесты, манифесты и два focused browser-прогона. Полный offline-flow всё ещё упирается в существующий строгий селектор закрытия увеличения; это не считается успешной проверкой offline-переходов.

## Контракт сцены

`video-forest` — седьмое место в `woodlands` и вход в фото-прогулку. Все шесть `PhotoWalkView` принадлежат этому месту. `findWoodland` разрешает новые подлокации до старых `getWalkView`, а `SearchScene` выбирает `PhotoWalkScene` до `StreetViewScene`. Экспериментальный панорамный renderer ожидает собственные `panoramaPoints` и не должен получать IDs фото-прогулки.

Маршрут: `video-forest` ⇄ `video-moss-stump` ⇄ `video-clearing`, откуда есть ветки к `video-deadwood` и к `video-trail` ⇄ `video-old-stump`. Это игровой граф, не геопривязка. Все пять соединений обратимы; все шесть мест достижимы. Кнопки в «Маршруте» допускают только соседние точки.

Кадры 1920×1080 полностью вписываются в доступную область с сохранением 16:9. На экранах других пропорций остаются поля: ориентиры не отрезаются. Навигационные метки заданы в процентах исходника. Переход — неподвижный opacity fade 240 мс; без поворота, перспективной деформации и искусственного движения камеры. Reduced-motion и `.calm` отключают затухание.

Точки осмотра — помеченные цифровые увеличения той же фотографии, не дополнительные точки съёмки. Прямоугольник `details` задаётся в процентах фотографии; равные процентные ширина и высота сохраняют её пропорции. Коэффициент увеличения = `100 / width`. После закрытия восстанавливается фокус на открывшей увеличение кнопке.

## Разделение ответственности

`photo-walk-core.ts` владеет DOM, декодированием изображений, переходом, точками осмотра, сессионным набором посещений и cleanup. Он не пишет в хранилище, не управляет hash и не создаёт аудиоплеер. React-адаптер передаёт `publicUrl`, действия маршрутизатора и настройки уменьшения движения. Другие места игры доступны через прежние `change`/`back` callbacks. Ключ `SearchScene` остаётся ID woodland, поэтому перемещение между подлокациями не размонтирует весь исследовательский сеанс.

История, сохранение находок и звук остаются в App. Существующие 17 находок не меняются. У новой сцены `spots: []`; отдельный счётчик «Находки» относится только к текущей сессии фото-прогулки. Для неизвестного аудио-ID существующий AudioManager выбирает сухой фоновый микс; отдельная звуковая дорожка здесь не добавлялась.

Следующее изображение декодируется до вызова `onNavigate`. Визуальный модуль блокирует повторный шаг; токены запросов отменяют устаревшие результаты. Ошибка не убирает предыдущую фотографию, доступен повтор. При размонтировании отключаются ResizeObserver, обработчики, анимация и ожидающие загрузки. По завершении перехода остаётся один слой изображения.

## Скрытые объекты для поиска

В шести подлокациях размещены 21 условная находка: миксомицеты, лишайники, небольшие грибы и мокрицы. `PhotoWalkObject` описывает `id`, `kind` (`myxomycete` / `lichen` / `fungus` / `creature`), `image`, `label`, короткое описание и прямоугольник `x`, `y`, `width`, `height`. Прямоугольник задаётся от верхнего левого угла исходного изображения в процентах. Объекты и фото лежат внутри одного `.pw-composite`, поэтому при осмотре они не разъезжаются.

До касания объект виден как тихая подсказка и доступная область 56×56 CSS px; после касания появляется один круглый просмотр с описанием. Первый поиск вызывает существующий тактильный cue `uncover`, повторное открытие не начисляет новую находку. Объекты не добавляются в семейный журнал и не получают видовые имена автоматически.

Четыре изображения в `public/assets/scene-07/objects/` — сгенерированное игровое оформление из `content/assets.manifest.json`, а не реальные фотографии. В карточке явно сказано: кадр видео оставлен без изменений, размещение условное и не является наблюдением. Исходные реальные кадры и их временные отметки остаются отдельным свидетельством.

## Происхождение и offline

`content/scene-07.manifest.json` содержит имена шести файлов, размеры, SHA-256 и точный PTS кадра. Исходный ролик не включён, EXIF/GPS/аудио не копировались. Не утверждается публичная лицензия видео. Публикация пакета запрошена пользователем отдельно; это не передача третьим лицам свободной лицензии на видео.

Реальные кадры не записываются в манифест ИИ-иллюстраций. `build-offline.mjs` читает отдельный манифест фото-прогулки и добавляет шесть файлов через существующий `publicPath`; четыре overlay-файла добавляются из общего asset manifest. Пути учитывают как `/`, так и `/mixor/`. Production build сформировал precache из 87 public assets и содержит все четыре overlay-файла; полный service-worker E2E пока не сертифицирован.

## Проверки и границы результата

Автоматически проверено:

- `npm run typecheck`;
- 14/14 domain/content/photo-walk Node-тестов;
- `npm run test:photo-walk` (6/6 тестов сцены);
- `npm run assets:validate` — 20 reference photos, 23 generated plates, 4 generated overlays, 20 registered audio assets;
- `npm run build` — Vite и offline precache, включая четыре overlay URL;
- focused Scene 07 browser test — по одному успешному прогону на phone и tablet, с проверкой 21 находки, диалога, фокуса, повторного открытия и смены кадра.

Полный browser sweep содержит 112 тестов: 100 прошли, 12 упали в существующих общих сценариях поиска/навигации (строгий дубликат кнопки закрытия, старые ожидания legacy Scene 07 и геометрии). Новый focused-тест Scene 07 в эти падения не входит. `npm run test:offline` дошёл до проверки cache, но остановился на том же существующем строгом селекторе; полноценный offline-flow не объявляется пройденным.

Визуальные результаты сохранены в `docs/screenshots/scene-07/` для phone и tablet. Не проверены на физическом устройстве: звук на слух, Safari, AWS deployment и пользовательская приёмка. Существующие ожидания числа сцен обновлены до семи; ожидание 17 находок сохранено.

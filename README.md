# Mixor — миксомицеты и маленькие открытия

**Семейная образовательная игра-исследование о миксомицетах и других амёбоидных организмах.** Большие настоящие фотографии, живой визуальный мир, дерево классификации, развитие, карты Земли и Германии и общий дневник собственных находок.

На прогулке родитель сохраняет фото и место с телефона. Дома ребёнок открывает ту же находку на планшете, рассматривает детали, сравнивает с атласом и продолжает исследование. Полноэкранные сцены, атмосферная музыка и звуки делают это игрой, а не административным приложением.

**Текущий статус: локальная игра-исследование.** Полноэкранная лесная сцена, восемь рисованных организмов, переключение на 20 настоящих фотографий, театр развития и полевой журнал. Музыка приглушена, отдельно звучат ветер и птицы. AWS, семейные аккаунты и межустройственная синхронизация ещё не реализованы.

## Запуск

Нужен Node.js 24 и npm. Из каталога репозитория:

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

На компьютере откройте `http://localhost:4173`. На телефоне или планшете — `http://IP-ЭТОГО-КОМПЬЮТЕРА:4173`; устройство должно иметь доступ к этому адресу и порту. `localhost` на телефоне означает сам телефон, а не сервер. Фотографии, рисунки и звук уже включены: ключи API для игры не нужны.

Выберите обитателя бревна, переключите «Иллюстрация / Настоящее фото», нажмите «Сделать открытие». Кнопка «Развитие» всегда в нижней панели. Для Physarum и Arcyria доступны пять основных стадий и объяснение ветвей покоя; для остальных шести отдельные циклы пока не подготовлены.

Для собранной версии:

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 4174
```

Офлайн-кэш работает в production-сборке на `localhost` или HTTPS после первого полного скачивания. По обычному удалённому HTTP игра запускается, но установка PWA и service worker недоступны. Не очищайте данные браузера, если в нём остались единственные копии находок. Несохранённая форма не переживает перезагрузку.

## Проверки и ассеты

```bash
npm run typecheck
npm run assets:validate
npx playwright install chromium
npm test
# При запущенном preview на localhost:4174:
npm run test:offline
```

Снимки тестовых экранов: `tmp/redesign-review/`. Тесты используют только синтетические находки. Проверки в браузере не заменяют испытаний реальных iPhone/iPad/Android и прослушивания на устройстве.

Рисунки созданы встроенным инструментом генерации изображений. [Промпты, исходники, раскладка стадий и происхождение](content/generated-art.manifest.json); [фотографии и лицензии](content/assets.manifest.json); [источники биологии](content/life-sources.json).

Перегенерировать новый звуковой пакет через ElevenLabs, используя существующий секрет в соседнем проекте:

```bash
npm run audio:generate
npm run audio:master
```

Это отдельная платная операция; для обычного запуска её выполнять не нужно. Генератор пропускает готовые файлы, поддерживает `--force` и повторяет временные ошибки сервиса. Перед публичным релизом нужны проверка условий аккаунта ElevenLabs и прослушивание качества петель. Шрифты Literata и Nunito Sans поставляются локально через Fontsource (SIL OFL).

Тексты лицензий шрифтов включены в сборку: [Literata](public/licenses/literata-OFL.txt), [Nunito Sans](public/licenses/nunito-sans-OFL.txt).

## Что принципиально

**Это должно ощущаться как игра.** Художественные сцены, большие изображения, музыка и звуковая атмосфера обязательны уже в раннем качественном результате. Не заменять их стандартным dashboard и обещанием «картинки добавим потом».

**Настоящие наблюдения важнее красивой выдумки.** Фото отделены от схем и генеративного оформления; находки — от полного ареала; классификация — от жизненного цикла; предположение ИИ — от проверенного определения.

**Семейные данные приватны и обратимы.** Отдельные аккаунты, общая коллекция, сохранение оригиналов, работа без связи, контролируемая синхронизация и полноценный экспорт. Репозиторий публичный: личные фото, реальные семейные координаты, экспорты и секреты сюда не добавлять.

## Задание следующему агенту

> Первый локальный маршрут уже собран по этапам 0–1. Следующий агент должен замкнуть телефон → AWS → планшет по этапу 2 и довести семейную версию до критериев этапа 3. Сохраняй научную честность, приватность, оригиналы фото и offline-черновики. API и схемы создавай с начала. Не выдавай placeholders, mock-sync или непроверенные лицензии за готовые функции. Результат сопровождай тестами, screenshots и честным списком ограничений.

AI-определение, сложная симуляция, 3D и детальные скачиваемые офлайн-карты — поздние отдельные этапы. Их отсутствие не должно блокировать основной исследовательский мир.

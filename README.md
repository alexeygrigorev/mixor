# Mixor: миксомицеты и маленькие открытия

Mixor - семейная образовательная игра об организмах, которые можно заметить на коре, листьях и гниющей древесине. Играйте в браузере на компьютере, телефоне или планшете.

Откройте [демо Mixor](https://alexeygrigorev.com/mixor/) в браузере, чтобы поиграть без установки. В этой сборке нет семейных аккаунтов и AWS, а записи журнала остаются в браузере, который открыл страницу.

В поиске доступны три прогулки: «Лесная прогулка» — 6 настоящих кадров и 21 игровая деталь, «Светлый лес» — 28 кадров и 8 деталей, «Сосновый бор» — ещё 36 кадров и 6 деталей. Между ракурсами есть переходы вперёд и назад; всего 70 мест и 35 находок. В новом ролике люди и вещи оставлены по разрешению пользователя; [отмеченные кадры можно позднее заменить или исключить из маршрута](docs/PINE_WALK_REVIEW.md). Сгенерированные сцены 1–6 убраны из игры, а старые ссылки открывают прогулку. Развитие восьми таксонов, дерево классификации и полевой журнал доступны отдельно.

Лес занимает весь экран телефона и компьютера. Перетаскивайте фотографию пальцем или мышью, приближайте двумя пальцами, колёсиком или кнопками. «Весь кадр» показывает фотографию целиком и возвращает прежний ракурс при повторном нажатии.

Переходите к следующему месту по стрелкам на земле или откройте «Маршрут», если нужная стрелка осталась за краем экрана. Значок подсказки отмечает следующую деталь без автоматического зачёта, а повторное нажатие убирает отметку.

Созданные для игры иллюстрации обитателей не подтверждают их присутствие в исходном видео.

В развитии листайте изображения стрелками или движением пальца, а для перехода к нужной стадии нажмите «Этапы». У каждого вида свои ранние рисунки, включая разрастание молодого плазмодия и появление первых тяжей перед развитой сетью.

Актуальные требования и история изменений записаны в [журнале обратной связи](docs/USER_FEEDBACK.md). Новую музыку и звуки ещё нужно проверить прослушиванием: отсутствие гула и приятное звучание нельзя подтвердить автотестами.

Семейные аккаунты, AWS-сохранение и синхронизация между устройствами ещё не реализованы. Записи журнала хранятся только в том браузере, где вы их сохранили.

## Запуск

Установите Node.js 24 и npm, затем запустите команды из каталога репозитория:

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

Откройте `http://localhost:4173` на компьютере или `http://IP-ЭТОГО-КОМПЬЮТЕРА:4173` на телефоне и планшете. Устройство должно иметь доступ к этому адресу и порту, а адрес `localhost` на телефоне указывает на сам телефон.

Для обычной игры ключи API не нужны, поскольку фотографии, рисунки и звук уже включены в репозиторий. После входа выберите занятие на главном экране. Из леса кнопка «Назад» возвращает к выбору места.

Игровые находки, посещённые остановки и ракурс сохраняются на устройстве. Для повторного поиска откройте «Маршрут» → «Новая прогулка» и подтвердите сброс только игрового прогресса. Журнал и изученные стадии сохраняются.

Музыка и природные звуки включены по умолчанию. Если браузер запрещает автоматическое воспроизведение, коснитесь обычной игровой кнопки: отдельно включать звук не нужно. Выбранную вами тишину и собственную громкость игра запоминает. Изменить их можно в настройках на главном экране и в лесной прогулке.

Для собранной версии используйте отдельный порт:

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 4174
```

Офлайн-кэш работает в production-сборке на `localhost` или HTTPS после первого полного скачивания. По удалённому HTTP игра запускается, но установка PWA и service worker недоступны.

Не очищайте данные браузера, если в нём остались единственные копии находок. Перед перезагрузкой сохраните форму, поскольку несохранённый черновик будет потерян.

## Проверки и подготовка звука

Запустите проверки кода, ассетов и браузерных сценариев:

```bash
npm run typecheck
npm run assets:validate
npx playwright install chromium
npm test
```

Для проверки в WebKit установите соответствующий браузер:

```bash
npx playwright install webkit
npm run test:webkit
```

При запущенном preview на `localhost:4174` проверьте офлайн-режим:

```bash
npm run test:offline
```

Тесты используют синтетические находки и не заменяют испытаний на реальных iPhone/iPad/Android. Декодирование аудио и вызов воспроизведения не заменяют прослушивание.

Генерация через ElevenLabs платная и не нужна для обычного запуска игры.

Для генерации нового звукового пакета используйте существующий секрет из соседнего проекта:

```bash
npm run audio:generate
npm run audio:master
```

Генератор пропускает готовые файлы и не перезаписывает исходники. Для локального мастеринга нужны `ffmpeg` и `ffprobe`, но новые обращения к ElevenLabs при нём не выполняются. Перед публичным релизом проверьте условия аккаунта ElevenLabs и прослушайте звук на целевых устройствах.

## Что сохранять при изменениях

Не выдавайте реконструкции за фотографии, а семейные гипотезы за экспертное определение. Не меняйте исходные определения снимков при обновлении справочника.

Храните личные фотографии и точные места приватно. Не добавляйте их в публичный Git вместе с EXIF, экспортами коллекции или секретами.

Сначала исправьте текущие игровые регрессии из списка обратной связи. Облако и карты остаются дальнейшим планом, а AI-определение, симуляция и 3D относятся к поздним этапам.

## Новая прогулка «Светлый лес»

Откройте **Найти в лесу → Светлый лес**. Это 28 отдельных полных кадров, не нарезка увеличений одной фотографии. Переходы сохраняют спокойное затухание 240 мс; возвраты и прогресс старой прогулки сохранены. Кадры и маленькие превью включены в офлайн-загрузку.

Происхождение, разрешение на публикацию, команды извлечения и статус проверок: [October walk review](docs/OCTOBER_WALK_REVIEW.md).

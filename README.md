# Mixor: миксомицеты и маленькие открытия

Mixor - семейная образовательная игра об организмах, которые можно заметить на коре, листьях и гниющей древесине. Играйте в браузере на компьютере, телефоне или планшете.

В локальной версии можно искать организмы в пяти лесных местах и изучать одиннадцать стадий развития каждого из восьми таксонов. На главном экране также доступны дерево классификации и полевой журнал. Сгенерированные изображения обозначены как реконструкции, а настоящие фотографии открываются отдельно с авторами и лицензиями.

В лесу коснитесь круга, чтобы открыть организм. Коснитесь найденного организма ещё раз, чтобы узнать о нём и перейти к развитию. Стрелками в углу можно менять место, оставаясь в поиске. В сценах с корнями и берёзами идёт дождь. В остальных местах дождя нет.

В развитии листайте изображения стрелками или движением пальца, а для перехода к нужной стадии нажмите «Этапы». У каждого вида свои ранние рисунки, включая разрастание молодого плазмодия и появление первых тяжей перед развитой сетью.

Мы заменили лесные фоны и изображения стадий по [вашей обратной связи](docs/USER_FEEDBACK.md). Новую музыку и звуки ещё нужно проверить прослушиванием: отсутствие гула и приятное звучание нельзя подтвердить автотестами.

Семейные аккаунты, AWS-сохранение и синхронизация между устройствами ещё не реализованы. Записи журнала хранятся только в том браузере, где вы их сохранили.

## Запуск

Установите Node.js 24 и npm, затем запустите команды из каталога репозитория:

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

Откройте `http://localhost:4173` на компьютере или `http://IP-ЭТОГО-КОМПЬЮТЕРА:4173` на телефоне и планшете. Устройство должно иметь доступ к этому адресу и порту, а адрес `localhost` на телефоне указывает на сам телефон.

Для обычной игры ключи API не нужны, поскольку фотографии, рисунки и звук уже включены в репозиторий. После входа выберите занятие на главном экране. Из леса кнопка «Назад» возвращает к выбору места, затем на главный экран. Из сведений о находке вы вернётесь в тот же лес, сохранив найденные организмы.

Для собранной версии используйте отдельный порт:

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 4174
```

Офлайн-кэш работает в production-сборке на `localhost` или HTTPS после первого полного скачивания. По удалённому HTTP игра запускается, но установка PWA и service worker недоступны.

Не очищайте данные браузера, если в нём остались единственные копии находок. Перед перезагрузкой сохраните форму, поскольку несохранённый черновик будет потерян.

## Проверки и подготовка звука

Запустите проверки кода, ассетов и браузерных сценариев:

```bash
npm run typecheck
npm run assets:validate
npx playwright install chromium
npm test
```

При запущенном preview на `localhost:4174` проверьте офлайн-режим:

```bash
npm run test:offline
```

Тесты используют синтетические находки и не заменяют испытаний на реальных iPhone/iPad/Android. Декодирование аудио и вызов воспроизведения не заменяют прослушивание.

Генерация через ElevenLabs платная и не нужна для обычного запуска игры.

Для генерации нового звукового пакета используйте существующий секрет из соседнего проекта:

```bash
npm run audio:generate
npm run audio:master
```

Генератор пропускает готовые файлы и не перезаписывает исходники. Для локального мастеринга нужны `ffmpeg` и `ffprobe`, но новые обращения к ElevenLabs при нём не выполняются. Перед публичным релизом проверьте условия аккаунта ElevenLabs и прослушайте звук на целевых устройствах.

## Что сохранять при изменениях

Не выдавайте реконструкции за фотографии, а семейные гипотезы за экспертное определение. Не меняйте исходные определения снимков при обновлении справочника.

Храните личные фотографии и точные места приватно. Не добавляйте их в публичный Git вместе с EXIF, экспортами коллекции или секретами.

Сначала исправьте текущие игровые регрессии из списка обратной связи. Облако и карты остаются дальнейшим планом, а AI-определение, симуляция и 3D относятся к поздним этапам.
